Accessibility test playerTry Tab + keyboard

Keyboard-first

Space/K play or pause; arrows and J/L seek; M mutes; F fullscreen; P PiP; C captions; ? opens shortcut help.

Assistive technology

The player uses semantic regions, slider attributes, visible focus states and an aria-live announcement surface for state changes.

Reduced motion

Sopplayer respects prefers-reduced-motion: reduce so transition-heavy control effects can be removed.
