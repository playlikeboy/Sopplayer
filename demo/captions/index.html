Captions and multilingual subtitles

Test native WebVTT subtitle tracks with Sopplayer using English and Spanish sample captions.

English + EspañolPress C for captions

Use native <track> markup

Sopplayer uses the browser’s text tracks and exposes caption selection through the player UI and API.

<video id="player" src="video.mp4" playsinline>
  <track kind="subtitles" label="English" srclang="en"
         src="subtitles-en.vtt" default>
  <track kind="subtitles" label="Español" srclang="es"
         src="subtitles-es.vtt">
</video>

<script>
  const player = new Sopplayer('#player');
  player.setTrack(0);
</script>
