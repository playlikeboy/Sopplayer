Sopplayer v2.0

Basic HTML5 video setup

A minimal integration using standard HTML5 video, the CDN bundles and a single constructor call.

Minimal setupWorking demo

Three pieces. That’s it.

Load the stylesheet, render your native video element, then initialize Sopplayer.

<!-- Styles -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SH20RAJ/Sopplayer@v2.0.0/dist/sopplayer.min.css">

<!-- Video -->
<video id="player" poster="poster.png" preload="metadata" playsinline>
  <source src="video.mp4" type="video/mp4">
</video>

<!-- Player -->
<script src="https://cdn.jsdelivr.net/gh/SH20RAJ/Sopplayer@v2.0.0/dist/sopplayer.min.js"></script>
<script>
  const player = new Sopplayer('#player');
</script>
