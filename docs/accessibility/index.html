Accessibility

Understand Sopplayer keyboard accessibility, focus behavior, ARIA semantics and reduced-motion support.

OverviewGetting startedAPI referenceConfigurationThemingAccessibilityMigrationSecurity

Keyboard controls

Space/K toggles playback; Left/Right and J/L seek; Up/Down adjusts volume; M toggles mute; F fullscreen; P PiP; C captions; 0–9 seek to a percentage; </> change playback rate; ? opens the shortcut dialog.

ARIA and focus

  • The player is exposed as a labeled region.
  • Progress and volume controls use slider-style semantics.
  • Interactive controls expose visible keyboard focus.
  • State changes can be announced through a polite live region.

Reduced motion

Sopplayer respects prefers-reduced-motion: reduce and removes transition-heavy effects when the user requests reduced motion.
